Set up a phone
  1. Install dhvani.apk on the phone. Android 10 or newer.
  2. Put the phone on the same Wi-Fi as this laptop.
  3. Open Dhvani, tap this laptop in the list (or type its address), enter the code, tap Start.
  4. Allow the sharing prompt. Only audio leaves the phone; the screen is never recorded.

Apps that block capture (some banking and DRM video apps) stay silent here. Android enforces that.
